## Asking for help

Give enough context for someone else to understand and try the same steps.

1. Describe what you were trying to do, what happened, and how to reproduce it.
2. Include your Jellyfin and JE versions, installation method, exact client/browser and device, and theme or relevant companions.
3. If it happens remotely, say how you access the server and whether direct local access works.
4. Add useful screenshots and [relevant logs](faq.md#how-do-i-gather-logs-for-bug-reports).

!!! warning

    Redact credentials and personal information before sharing screenshots or logs.

Keep follow-up details in the same discussion or issue, and allow time for community members to respond.

## Other ways to contribute

You can help by testing the steps in a report, explaining a workaround, improving documentation, or translating strings.

For code contributions, use the [GitHub repository](https://github.com/n00bcodr/Jellyfin-Enhanced) and [Project Structure](../advanced/project-structure.md) to find the relevant code area.
