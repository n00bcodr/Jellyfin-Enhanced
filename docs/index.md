# Jellyfin Enhanced

<p class="je-tagline">Make Jellyfin yours with better browsing, playback and connected services.</p>

<p class="je-intro">JE adds browsing and playback tools to your server's Jellyfin web interface. Selected server features also work with native clients.</p>
