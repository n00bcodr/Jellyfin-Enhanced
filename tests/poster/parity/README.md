# Poster resolver parity

Run `node tests/poster/parity/run.mjs --offline` with Node 26.2.0 and .NET 10 installed. The language/casing oracle uses ICU 78.3, CLDR 48 and Unicode 17, matching the generated production tables; another ICU version can legitimately differ and must be reviewed rather than silently accepted. This generates disposable inputs under ignored `data/`, evaluates the actual JavaScript tag modules and the C# resolver, and compares their results across 84 integrated profiles and 131 synthetic metadata fixtures (including the empty administrator profile). The additional empty synthetic administrator profile verifies the no-items case. No server or credentials are required. Run `npm ci` first for the fixed-clock Status oracle. Language profiles cover subtitle includes, CC markers, codes, combined caps, audio-count modes and regional/priority policies. The run also compares language display names and Unicode casing. Any mismatch returns a nonzero exit code. Status adds 50 fixed-clock web/native fixtures covering each family, switches, windows, finale precedence, missing keys, compact Bands and English/German/French weekdays and UTC/Perth/New York calendar/DST boundaries. Bands profiles cover default/custom/admin slots, hidden groups, order, caps and compact labels. Centre-anchor fixtures cover both legacy position strings and the Corners profile for all five additional anchors.

Offline mode deletes and recreates `data/inputs`, so a previous live-server capture never mixes into an offline run; keep captures you want elsewhere (`fetch-inputs.mjs --out DIR`). Existing live-server mode and `--skip-fetch` remain available. Offline parity tests resolution behavior in the existing sandbox, not browser pixels or native-client request handling.

`python tests/runner/poster.py` additionally runs pipeline checks and embedded rendering asset checks against both supported Skia library lines. Artifacts default to `artifacts/regression/poster`. Native checks require Linux Skia/font dependencies and .NET 10 runtime compatible with the plugin's selected Jellyfin package.
