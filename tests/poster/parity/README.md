# Poster resolver parity

Run `node tests/poster/parity/run.mjs --offline` with Node 26.2.0 and .NET 10 installed. The language/casing oracle uses ICU 78.3, CLDR 48 and Unicode 17, matching the generated production tables; another ICU version can legitimately differ and must be reviewed rather than silently accepted. This generates disposable inputs under ignored `data/`, evaluates the actual JavaScript tag modules and the C# resolver, and compares their results across 277 integrated profiles and 353 synthetic metadata fixtures (including the empty administrator profile). The additional empty synthetic administrator profile verifies the no-items case. No server or credentials are required. Run `npm ci` first for the fixed-clock Status oracle. Language profiles cover subtitle includes, CC markers, codes, combined caps, audio-count modes and regional/priority policies, including personal lists, canonical aliases, grouped flags, strict inheritance/overrides, empty opt-out and invalid-document fallback. The run also compares language display names and Unicode casing. Any mismatch returns a nonzero exit code. Status adds fixed-clock web/native fixtures covering each family, switches, windows, finale precedence, missing keys, compact Bands all shipped locales for short dates (including Persian calendar boundaries), English/German/French weekdays and UTC/Perth/New York calendar/DST boundaries. Bands profiles cover default/custom/admin slots, hidden groups, order, caps and compact labels. Centre-anchor fixtures cover both legacy position strings and the Corners profile for all five additional anchors. Edge-spacing fixtures put groups on all nine anchors at Tight and Flush (each group then carries the inset `e`, read on the web from the layout stylesheet's `--je-edge`), plus an inherited administrator default and a legacy document that keeps the default inset. The `colours` step compares the Poster Tag Styles preset's artwork colours (`Services/PosterTags/PosterColour.cs`) with `js/tags/tag-poster-colours.js` on synthetic solid, two-tone, gradient, letterboxed, translucent and noise posters: exactly at sample size, and within a stated tolerance for full-size posters, whose downscale differs between the browser and Skia. Custom fixtures cover icon/name chips, retired ids, rule-order changes, caps, profiles and administrator defaults. Genre chips compare name, glyph and Tag Styles label (`data-je-genre` on the web, `TagStyleCatalog.GenreKey` natively), so aliases, translations and names outside the table resolve to the same label on both sides; the run checks the generated genre table (`scripts/generate_genre_labels.py --check`) first. Item-look profiles (`item-looks`, `item-looks-bands-default`, `item-looks-legacy`) resolve each item with its own look on both sides (`resolveLayout` with the item's data on the web, `PosterTagSettings.ForItem` natively) over seven fixtures with real item ids: a user lock, an administrator item look, both (the lock wins), a series look its episode inherits and a series-poster-only look its episode does not; looks carry caps, size and gap (compared as `s`), edge spacing, positions and hidden groups, on a normalized Corners, a normalized Bands and a legacy document.

Offline mode deletes and recreates `data/inputs`, so a previous live-server capture never mixes into an offline run; keep captures you want elsewhere (`fetch-inputs.mjs --out DIR`). Existing live-server mode and `--skip-fetch` remain available. Offline parity tests resolution behavior in the existing sandbox, not browser pixels or native-client request handling.

`python tests/runner/poster.py` additionally runs pipeline checks and embedded rendering asset checks against both supported Skia library lines. Artifacts default to `artifacts/regression/poster`. Native checks require Linux Skia/font dependencies and .NET 10 runtime compatible with the plugin's selected Jellyfin package.

Size/gap profiles cover every non-default value, administrator inheritance and version-0 isolation. The effective settings are compared alongside tags; backend rendering regressions additionally check scaled metrics and cached-versus-uncached pixels.
`node scripts/generate_status_dates.mjs` generates native short-date patterns with the exact web `Intl` options. The vocabulary generator runs its generation/check too. `status-short-dates.json` contains month-specific literals (such as Catalan connectors), month names, calendar and numbering data, deduplicated behind locale mappings. The generator enumerates CLDR-named territories for every shipped language/script and Chinese script parents; `tests/fixtures/native-status-dates.json` verifies every generated region at four dates in backend tests. Fixed-clock Status parity also covers common regions and Unicode extensions.

Natural overflow geometry and chip pixels are covered separately from resolver parity: see [`tests/fixtures/native-overflow/README.md`](../../fixtures/native-overflow/README.md). The production browser fitter and native planner both retain nine narrow `4I` chips plus `+3`; dedicated `+1`/`+12` measurements and Corners/Bands pixel fixtures protect the `.je-tag-more` style.

Item-look profiles also cover Flush single-chip caps on legacy and normalized documents, including AC-3 audio facts. Their native oracle uses full labels on Corners and compact labels on Bands. Item-look fallback profiles cover Caption, Summary and Minimal with Quality, Genre and Rating off, for personal locks and server-wide looks; visible groups retain their Corners fallback positions.
