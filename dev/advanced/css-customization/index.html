    CSS Custom Styling¶

    Use Custom CSS to change the appearance of Jellyfin Enhanced's web overlays, tags, settings panel, and notifications.

    These recipes target elements created by JE's injected web client. The feature must be enabled and its metadata available before CSS can style it.

    For feature setup and client requirements, see Compatibility, Tags & Badges, and Enhanced Settings.

    Applying Custom CSS¶

    As a Jellyfin administrator:

    1. Open Dashboard → Branding.
    2. Paste the recipes you want into Custom CSS Code, alongside your existing CSS.
    3. Click Save.
    4. Reload the web client. Use Ctrl+F5 for a hard refresh in browsers that support it.

    This applies CSS server-wide to web clients that load Jellyfin's Custom CSS. Test the result on desktop and phone layouts.

    To undo a recipe, remove its rules, save, and reload.

    When a rule has no effect¶

    Inspect the element in your browser's developer tools and check its actual classes, attributes, and computed styles. A disabled feature, absent metadata, or a native poster image can leave nothing for the selector to match.

    The examples use !important where needed to beat built-in colors, inline styles, or responsive rules. Scope changes to a JE container and keep hover, selected, disabled, and focus states usable.

    How CSS rules compete

    JE uses ordinary stylesheets, ordinary inline styles, and !important declarations:

    • An ordinary inline style beats ordinary stylesheet rules.
    • An important stylesheet rule can override an ordinary inline style.
    • Among competing important rules in these stylesheets, higher specificity wins. Equal specificity falls back to document order.

    JE appends shared styles, pause-screen styles, and Tag Styles overrides to the document head. On Jellyfin 12 web, Custom CSS is rendered in the body, after those head styles. Equal-specificity rules can therefore win even if JE injected its style later in time.

    The panel also embeds its own style element in the body. Inspect the winning declaration instead of assuming all styles have the same order, especially on Jellyfin 10.11.

    Pause Screen¶

    The pause screen shows artwork, item details, plot, and a progress snapshot while playback is paused. Enable it in your personal Playback Settings, pause a video, and leave the player idle to preview your CSS.

    The administrator sets the default; viewers can override it in the Enhanced panel.

    Setting Default What it does
    Enable Custom Pause Screen (admin) / Custom Pause Screen (viewer) On PauseScreenEnabled: enables the pause overlay.
    Delay before showing (seconds): (viewer) 5 PauseScreenDelaySeconds: delay during paused inactivity; the panel accepts 1–60 seconds.

    Clicks, touches, key presses, scrolling, and mouse movement beyond the movement threshold reset the inactivity timer.

    Missing logo or disc artwork stays hidden. Artwork lookup considers the item and applicable parent/series artwork.

    Elements and visibility¶

    Use these selectors to style or hide individual parts of the pause screen.

    Element CSS selector What it contains
    Dialog #pause-screen-overlay Outer overlay; visible when aria-hidden="false".
    Content #pause-screen-content Backdrop, logo, details, plot, progress, and close button.
    Logo #pause-screen-logo Item logo image.
    Details #pause-screen-details Item metadata.
    Plot #pause-screen-plot Scrollable synopsis.
    Progress wrapper #pause-screen-progress-wrap Bar and labels.
    Progress track #pause-screen-progress-bar Track behind the fill.
    Progress fill #pause-screen-progress-bar > span Playback snapshot; width is written inline.
    Progress labels #pause-screen-progress-meta .progress-time, .progress-percentage, .progress-ends-at.
    Spinning disc #pause-screen-disc Disc image; a direct child of the overlay.
    Backdrop #pause-screen-backdrop Background artwork layer.
    Close button #pause-screen-close-btn Dismisses the overlay for this pause without resuming.

    Hide any optional region using its ID. For example:

    #pause-screen-logo,
#pause-screen-details,
#pause-screen-plot,
#pause-screen-progress-wrap,
#pause-screen-disc,
#pause-screen-backdrop {
    display: none !important;
}

    Keep only the selectors for regions you want to hide. You can style the remaining regions independently:

    #pause-screen-progress-bar > span {
    background: gold !important;
}

#pause-screen-progress-meta .progress-ends-at {
    display: none !important;
}

#pause-screen-overlay #pause-screen-progress-meta .progress-percentage {
    color: gold !important;
    font-weight: bold !important;
}

#pause-screen-plot {
    height: 30vh !important;
    overflow-y: auto !important;
}

#pause-screen-disc {
    animation: none !important;
}

#pause-screen-backdrop {
    opacity: 0.15 !important;
}

    The progress fill is not a seek control. Press Space or Enter to resume. Clicking or touching an empty overlay/content surface schedules resume after 500 ms.

    Note

    Hide individual regions rather than the dialog itself. While active, JE adds .pause-screen-active to the HTML root and suppresses parts of the player's controls. Hiding the whole dialog with CSS leaves that state active.

    Keep the close button and the focus helpers (#pause-screen-focus-start, #pause-screen-focus-end) usable, or turn off Custom Pause Screen to remove the feature.

    --pause-screen-details-left 8vw Details and progress wrapper left position.

    --pause-screen-text-size 1.2rem Details font size.
    --pause-screen-plot-top 55vh Plot top position.
    --pause-screen-plot-left 8vw Plot left position.
    --pause-screen-plot-max-w 50vw Plot maximum width.
    --pause-screen-plot-font 1.25rem Plot font size.
    --pause-screen-progress-top 85vh Progress wrapper top position.

    Responsive layouts and disc animation

    Built-in layouts adjust root defaults at widths of 1400px and 768px, and in landscape at heights of 500px or less.

    Some phone positions, font sizes, and plot dimensions are set directly on elements, so variables do not control every dimension. Narrow layouts hide the disc; the later landscape rule can show it again. Reduced-motion preferences stop its rotation.

    Tags¶

    Poster tags use separate containers for quality, genre, language, rating, and age-rating badges. People tags decorate cast portraits on detail pages. Enable the relevant personal setting in Media Tags before trying a recipe.

    Prerequisites and placement¶

    The administrator's Media Tags settings (the configuration page's Media Tags tab) provide defaults. All six tag features start off at factory defaults.

    Setting Default What it does
    Enable Quality Tags (admin) / Show Quality Tags (viewer) Off QualityTagsEnabled: resolution, source, format, and sound badges.
    Enable Genre Tags (admin) / Show Genre Tags (viewer) Off GenreTagsEnabled: genre icons and hover labels.
    Enable Language Tags (admin) / Show Language Tags (viewer) Off LanguageTagsEnabled: audio-language flags.
    Enable Rating Tags (admin) / Show Rating Tags (viewer) Off RatingTagsEnabled: community and critic scores.
    Enable Age Rating Tags (admin) / Show Age Rating Tags (viewer) Off AgeRatingTagsEnabled: official age/content certification.
    Enable Status Tags (admin) / Show Status Tags (viewer) Off StatusTagsEnabled: Just Added, New Movie/Series/Episode and trending rank badges.
    Enable Logo Tags (admin) / Logos (viewer) Off LogoTagsEnabled: streaming service, network or studio logos.
    Enable People Tags (admin) / Show People Tags (viewer) Off PeopleTagsEnabled: cast ages, birthplace, and deceased status.
    Hide tags on hover (admin and viewer) Off TagsHideOnHover: adds body.je-tags-hide-on-hover; an important hover rule hides the poster tag host.

    New user settings for the eight tag features are seeded from the plugin configuration. Existing non-null user values take precedence over admin defaults. Changing a default does not replace a saved personal choice. See Settings Overview for default management.

    Server and saved user properties use PascalCase. Resolved client settings use camelCase, such as qualityTagsEnabled.

    Users can change Hide tags on hover later in their personal Media Tags section (Layout tab).

    If tag data is stale or missing, also check the server's cache configuration under Media Tags → Server:

    Setting (admin) Default What it does
    Exclude libraries from the tag cache Off TagCacheExcludeLibraries: enables library exclusions.
    Libraries to exclude Empty TagCacheExcludedLibraryIds: selected libraries to skip; an empty selection excludes nothing.

    Exclusion changes affect the next cache rebuild. Click Save Settings, then open Admin → Tag Cache and click Rebuild Server Tag Cache. Confirm the full rebuild. See Tags & Badges for cache operation; CSS only styles the resulting elements.

    Use the Position pills on the Groups tab and the layout tiles on the Layout tab of Media Tags to move tag containers.

    The normal poster structure places .je-tag-host inside .cardScalable, before .cardOverlayContainer. Fallback targets are used when that structure is unavailable: a list row's image gets its own .je-tag-host.

    <div class="cardBox">
  <div class="cardScalable">
    <div class="cardImageContainer"></div>
    <div class="je-tag-host" data-je-layout="caption">
      <div class="je-tag-slot" data-je-slot="poster">
        <div class="status-overlay-container" data-je-group="status">…</div>
      </div>
    </div>
    <div class="cardOverlayContainer"></div>
  </div>
  <div class="je-tag-slot je-tag-caption" data-je-slot="caption">
    <div class="quality-overlay-container" data-je-group="quality">…</div>
  </div>
  <div class="cardText">…</div>
</div>

    data-je-layout on the host names the layout (corners, bands, caption, summary, minimal). Each place is a .je-tag-slot with data-je-slot:

    Layout Slots
    Corners tl, tc, tr, ml, c, mr, bl, bc, br (3×3 order)
    Bands top, bottom
    Caption poster, plus the outlet .je-tag-caption (caption) between .cardScalable and the title block, outside the image
    Summary pill (holds .je-tag-pill with .je-tag-pill-fact spans), hover
    Minimal top, dots (holds .je-tag-dots with .je-tag-dot spans whose data-je-dot is resolution, range, audio or codec), corner, hover

    Group containers keep their classes and chip markup in every layout and carry data-je-group. In flowing slots (the bottom band, the caption and the hover scrim) containers use display: contents, so their chips wrap together in one row. The hover slot fades in on .card:hover and .card:focus-within.

    What does not fit is hidden whole, never cut: once a card is laid out, chips that would wrap past the two rows of the caption strip, the bottom band or the hover scrim get data-je-overflow (lowest priority first) and the slot ends with a .je-tag-more chip reading +N (it takes no pointer or focus). The names of the hidden chips go in one .je-tag-more-tip element inside .je-tag-host: the card's image link points at it with aria-describedby, and it shows as a small tooltip at the top of the image while the card is hovered or focused. A hover scrim on a card too short for even one row of chips gets data-je-overflow itself. A summary pill too wide for its card hides its lowest-priority .je-tag-pill-fact (and the separator before it) the same way. [data-je-overflow] is display: none !important.

    Tag container Position property Factory corner
    .quality-overlay-container QualityTagsPosition top-left
    .genre-overlay-container GenreTagsPosition top-right
    .language-overlay-container LanguageTagsPosition bottom-left
    .rating-overlay-container RatingTagsPosition bottom-right
    .age-rating-overlay-container AgeRatingTagsPosition bottom-right
    .status-overlay-container StatusTagsPosition top-right
    .custom-overlay-container CustomTagsPosition top-left

    Native poster pixels now include Status and the saved Bands layout. They have no DOM/CSS hooks: use Tag Styles → Status to colour the whole group or an individual badge (including schedule/milestone/series-state labels). Web hooks remain .status-tag, data-je-status, .je-tag-slot[data-je-slot="top"|"bottom"] and .je-tag-more; no new web selectors are required. Native strips use fixed image-width sizing and +N without a hover tooltip.

    In the Corners layout, containers carry data-je-corner with one of the nine stored position values (top-left, top-center, top-right, center-left, center, center-right, bottom-left, bottom-center, bottom-right). Containers sharing a corner stack in their slot with a 4px gap (top corners downward, bottom corners upward) instead of inline transforms. When a group is set to top right and the card shows Jellyfin's played or unplayed-count indicator, the host gets data-je-indicator-gap and the tr slot moves below it. Settings saved before layouts existed keep the original rule instead (their host carries data-je-legacy): only the container of a group set to exactly top-right carries data-je-indicator-gap and moves below the indicator, with the containers stacked after it; and on screens up to 480px wide the rating, age rating and status containers sit 4px from the card edges instead of 6px. The centre hooks are tc (top centre), bc (bottom centre), ml (left centre), mr (right centre) and c (centre). The rows use horizontal flex wrapping with centred chips; side anchors use columns aligned to their edge. Their group wrappers use display: contents, retaining the chip classes. Batched measurements set --je-anchor-reserve on these slots to keep them clear of occupied corner stacks; --je-anchor-top and --je-anchor-bottom clear native web overlays. Their excess chips use the same data-je-overflow and .je-tag-more hooks as flowing layouts. The original four corner geometry rules stay unchanged. Position slots rather than containers when you move tags: a container's own top, left or transform no longer places it.

    Edge spacing other than Default marks a Corners host with data-je-edge="tight" or data-je-edge="flush" and sets --je-edge (3px or 0px) on it; every anchor's offset, the corner containers' size limits, the centre budgets' defaults and the indicator gap use it. Default has no marker and keeps the original rules. A flush host clips its chips with overflow: hidden and border-radius: var(--je-card-radius), where --je-card-radius is the artwork's corner radius, measured once per card; box chips touching an edge get square corners there. For example, .je-tag-host[data-je-edge="flush"] .quality-overlay-label { border-radius: 0; } makes every flush quality chip square.

    A card whose look comes from a lock (see Rules and locked items) has data-je-locked="1" on its .je-tag-host; nothing styles it by default. For example, .je-tag-host[data-je-locked="1"] { outline: 1px dashed #fff8; } marks locked cards. A server-wide item look does not set it.

    The per-item editor (One item's look) is a dialog .je-tie inside .je-tie-backdrop; its sample card is .je-tie-card, and its row in Jellyfin's ⋮ menu is .actionSheetMenuItem[data-id="je-media-tags"]. Its Undo message is .je-tie-toast.

    The Media Tags import, export and preset dialogs (in the settings panel and on the configuration page's Media Tags tab) are .je-pt-backdrop > .je-pt-dialog[role="dialog"], with .je-pt-change / .je-pt-skip rows (.je-pt-from, .je-pt-to, .je-pt-reason) and .je-pt-btn buttons ([data-primary] for the main action). The panel's preset rows are .je-mth-tp-item inside [data-tp-source="builtIn" | "offered" | "mine"].

    Poster tags generally ignore pointer input. Container-query sizing adapts badges to card width, with separate mobile rules. Fixed sizes can crowd small posters.

    Processing markers such as data-je-quality-tagged, data-je-genre-tagged, data-je-language-tagged, data-je-rating-tagged, and data-je-age-rating-tagged record processing. They do not guarantee a visible badge.

    Tag Styles and native posters¶

    Use the built-in Tag Styles editor for supported colors; that guide covers presets, tabs, scope, opacity, and bulk controls. See Native Poster Tags for native-client setup and refresh requirements. CSS remains useful for web shape, sizing, visibility, and other surfaces.

    Web overrides use important selectors. Their specificity is (0,4,0) for quality, (0,3,0) for age and rating chips, and (0,2,0) for the whole genre group ((0,3,0) for one genre, through data-je-genre). These beat simple color recipes; more specific important Custom CSS can override them.

    Critic styles also match user-review chips because those share .rating-tag-critic.

    Under the Poster preset, each card's .cardBox (a list row's image element) carries data-je-poster-colour="1", data-je-poster-key (item, image type, index and image tag) and three custom properties taken from its artwork: --je-tag-bg, --je-tag-border and --je-tag-fg. The Poster rules paint the chips (and the summary pill) with them at the same specificity as the override rules above and before them, so group and tag colours still win. Use the variables in your own CSS to match other elements to the artwork, for example [data-je-poster-colour] .je-tag-more { background: var(--je-tag-bg); color: var(--je-tag-fg); }. A card whose artwork could not be read has no marker and keeps the Default colours.

    Checking Tag Styles through the API

    For troubleshooting, authenticated GET /JellyfinEnhanced/tag-styles returns effective web overrides only when enabled and targeting web or both. Otherwise it returns empty styles. Unavailable configuration returns HTTP 503.

    GET /JellyfinEnhanced/tag-styles/catalog additionally requires an administrator. See the API reference.

    The page-wide Tag Styles rules skip tags inside an element with the data-je-tag-styles-scope attribute. The configuration page's Media Tags tab marks its preview (#jeTaPreviewBody) this way and styles it with the server's Tag Styles in the je-tag-admin-preview-styles stylesheet, fetched again after a Tag Styles save, whenever the page is shown again, and after Take theirs.

    CSS selectors cannot individually restyle pixels drawn into a poster image. Use Tag Styles targeting poster images for supported color changes; native output requires Native Poster Tags.

    Quality Tags¶

    Quality badges use .quality-overlay-label and a normalized data-quality value. Inspect the attribute rather than matching the displayed text: a badge reading ATMOS 7.1 has data-quality="ATMOS".

    Category Recognized data-quality values Additional class
    Resolution 8K, 4K, 1440p, 1080p, 720p, 576p, 480p, LOW-RES, SD .resolution
    Source BluRay, HD DVD, DVD, VHS, HDTV, Physical .other-quality
    Dynamic range Dolby Vision, HDR10+, HDR10, HDR .video-codec
    Special format IMAX, 3D .video-codec
    Video codec AV1, HEVC, H265, VP9, H264, VP8, XVID, DIVX, WMV, MPEG2, MPEG4, MJPEG, THEORA .video-format
    Sound ATMOS, DTS-X, TRUEHD, DTS, Dolby Digital+, 7.1, 5.1 .audio-codec

    The codec class names are historical: .video-format means video codec, while .video-codec means HDR or special format. Unknown labels use .other-quality.

    Which quality values can appear
    • SD is recognized for sorting/styling, but the current resolution detector emits the other eight resolution values. Unknown or stale cached values can also pass through.
    • Only the best resolution is retained.
    • Source detection requires a .disc media stub and selects one source badge.
    • Standalone channel fallback produces 7.1 or 5.1. 2.0 can be appended to a codec label but is not a standalone fallback.

    Use the Quality Tags category controls before CSS hiding; that guide covers administrator defaults, personal overrides, and category order.

    Resize all quality badges:

    .quality-overlay-label {
    font-size: 0.8rem !important;
    padding: 3px 10px !important;
}

    Change a color while allowing admin Tag Styles to take precedence:

    div.quality-overlay-container .quality-overlay-label[data-quality="4K"] {
    background: purple !important;
    color: #fff !important;
}

    This selector beats the built-in (0,3,0) color rule, but loses to the editor's (0,4,0) override. To deliberately override the editor too, use:

    .quality-overlay-container.quality-overlay-container
.quality-overlay-label.quality-overlay-label[data-quality="4K"] {
    background: purple !important;
    color: #fff !important;
}

    Hide unwanted values:

    .quality-overlay-label[data-quality="H264"],
.quality-overlay-label[data-quality="Physical"] {
    display: none !important;
}

    Customize media-stub source colors:

    div.quality-overlay-container .quality-overlay-label[data-quality="BluRay"] {
    background: rgba(0, 150, 255, 0.95) !important;
    color: #fff !important;
}

div.quality-overlay-container .quality-overlay-label[data-quality="HD DVD"] {
    background: rgba(200, 0, 50, 0.95) !important;
    color: #fff !important;
}

div.quality-overlay-container .quality-overlay-label[data-quality="DVD"] {
    background: rgba(200, 100, 0, 0.95) !important;
    color: #fff !important;
}

div.quality-overlay-container .quality-overlay-label[data-quality="VHS"] {
    background: rgba(160, 82, 45, 0.95) !important;
    color: #fff !important;
}

div.quality-overlay-container .quality-overlay-label[data-quality="HDTV"] {
    background: rgba(100, 100, 100, 0.95) !important;
    color: #fff !important;
}

    Sound-tag language selection¶

    Audio preferences can change which sound badge appears for the same item across viewers.

    Setting Default What it does
    Preferred Audio Language for Sound Tags (admin) No preference (best track overall) ("") QualityTagsPreferredAudioLanguage: server language preference.
    Use Each User's Jellyfin Audio Language (admin) Off QualityTagsAudioLanguageFromUser: uses each viewer's Jellyfin audio preference as server policy.
    Preferred audio language for the sound tag (viewer) Server default ("") Overrides server policy with My Jellyfin audio language (auto), No preference (best track overall) (none), or a language code.

    Matching tries regional language matches, then base-language matches, then all tracks. Inspect the resolved badge before targeting an audio data-quality value.

    Genre Tags CSS¶

    Use these hooks to style genre icons and their hover labels. Up to three genres appear.

    • Icons use .genre-tag > .je-msym-outlined.
    • Text uses .genre-text inside .genre-overlay-container.
    • data-je-genre holds the genre's Tag Styles label: the canonical English genre its icon stands for (horror, science fiction, game-show…), the same for every spelling and translation (Sci-Fi and Ciencia ficción are both science fiction), or other. Tag Styles colour one genre through it: .genre-tag[data-je-genre="horror"].
    • Target the exact name the item has through its title, such as .genre-tag[title="Drama"].

    By default, text appears on hover and floats inward from the selected corner. To keep labels visible inside wider chips:

    1. Turn off Hide tags on hover (with it on, the names are hidden on the poster).
    2. Apply the following CSS:
    .genre-tag {
    width: auto !important;
    border-radius: 14px !important;
    gap: 4px;
    padding: 0 6px;
}

.genre-tag .genre-text {
    position: static !important;
    transform: none !important;
    opacity: 1 !important;
}

    Changing display alone does not reveal text hidden by opacity. Every genre chip carries its .genre-text span; in the Summary and Minimal hover reveal it is shown inline. Long labels can cover more of the poster.

    When a card is revealed (hovered, focused, or a preview's Hover view), each floating name is fitted to the room beside its icon and marked data-je-genre-fit: side (beside its icon, with an inline max-width), list (one line under or over a row of icons, with inline left, top and max-width) or hidden (no room; display: none). Names your CSS makes position: static, as above, are never marked or moved. The same pass places a card's .je-tag-more-tip (the names behind its +N chips) with an inline top and marks it data-je-tip-fit: placed, or hidden (no free band; display: none).

    Language Tags CSS¶

    Use .language-overlay-container and .language-flag to style language flags. Personal Language → Priority changes the eligible chips and their order before caps; hiding a chip with CSS does not promote another language. Tooltips and accessible labels identify Audio/Subtitles, full language names and partial coverage; count badges include the count and audio-language names. Existing chip selectors are unchanged.

    The personal hub editor is scoped to #jellyfin-enhanced-panel .je-language-priority. Its ordered list uses [data-language-priority-list] and [data-language-priority-code]; these are settings controls, separate from poster chips.

    • data-lang is a lowercase flag-country code: jp targets the Japanese flag, while Japanese's language code is ja.
    • data-lang-name contains represented language names.
    • Partial flags also have .language-flag-partial and data-partial="true".
    Setting (admin) Default What it does
    Priority Languages Empty LanguageTagsPriority: prioritizes language flags.
    Only Show Priority Languages Off LanguageTagsPriorityStrict: restricts output to the priority list.
    Merge Regional Variants Off LanguageTagsMergeRegions: regional and script variants share the base language's flag.

    Flags are deduplicated by country and limited to three. Full flags normally precede partial flags, but priority ordering takes precedence.

    When different languages share a flag, it is partial only if all represented languages are partial. Hiding a flag with CSS does not cause a fourth flag to render.

    .language-flag {
    width: 30px !important;
    height: auto !important;
}

.language-flag[data-lang="jp"] {
    display: none !important;
}

    Restyle flags for audio that does not cover every episode of a series/season:

    .language-flag-partial {
    opacity: 1 !important;
    filter: none !important;
    outline: 2px solid gold !important;
    /* To hide partial flags instead: display: none !important; */
}

    Partial flags normally use opacity 0.55, saturation 0.5, a dashed outline, and a dark shadow ring.

    This recipe keeps the existing ring and outline offset. Add box-shadow: none !important or outline-offset: 0 !important if desired.

    Rating Tags CSS¶

    Use .rating-overlay-container, .rating-tag, and .rating-text to style poster scores. Community and critic chips have separate hooks:

    *arr Tag Links¶

    Enable Show synced tags as links under the admin *arr → Tags Sync section. Matching tags already present on an item become links in .itemExternalLinks on its detail page. Importing tags is a separate operation; see *arr Features.

    Setting (admin) Default What it does
    Show synced tags as links On ArrTagsShowAsLinks: creates links for matching item tags.
    Tag Prefix JE Arr Tag: ArrTagsPrefix: case-sensitive prefix used to identify tags.
    Show as Links Filter Empty ArrTagsLinksFilter: optional allow list of unprefixed names, one per line.
    Hide Specific Links Filter Empty ArrTagsLinksHideFilter: hides matching names, one per line; takes precedence over the allow list.

    Filter comparisons ignore case after reconstructing each full prefixed name. Initial prefix matching is case-sensitive.

    The factory prefix includes a trailing space. If the admin prefix field is empty on load or save, the admin UI substitutes the default, JE Arr Tag:. Inspect the actual configured prefix.

    The following admin settings under Tags Sync control tag imports:

    Setting Default What it does
    Enable Tags Sync Off ArrTagsSyncEnabled: allows the sync task to import tags from configured Radarr and Sonarr instances.
    Clear old tags before sync On ArrTagsClearOldTags: removes existing tags with the configured prefix before adding the imported tags.
    Sync to Jellyfin Filter Empty ArrTagsSyncFilter: restricts which tags are imported; empty syncs all tags.

    The *Sync Tags from arr to Jellyfin task has no default triggers; run it manually or configure a schedule.

    Link structure and attributes¶

    This illustrative link uses the factory prefix. Replace the item/server placeholders with actual values when inspecting your page:

    <a is="emby-linkbutton"
   class="button-link emby-button arr-tag-link"
   href="#!/list.html?type=tag&amp;tag=JE%20Arr%20Tag%3A%20in-netflix&amp;serverId=SERVER_ID"
   title="View all items with tag: JE Arr Tag: in-netflix"
   data-item-id="ITEM_ID"
   data-id="in-netflix"
   data-tag="JE Arr Tag: in-netflix"
   data-tag-name="in-netflix"
   data-tag-prefix="JE Arr Tag: ">
  <span class="arr-tag-link-icon" aria-hidden="true" style="margin-right: 5px;">
    <!-- JE icon markup; depends on Use Icons in UI and Icon Style -->
  </span>
  <span class="arr-tag-link-text"
        data-id="in-netflix"
        data-tag="JE Arr Tag: in-netflix"
        data-tag-name="in-netflix"
        data-tag-prefix="JE Arr Tag: ">JE Arr Tag: in-netflix</span>
</a>
    Hook Meaning
    .arr-tag-link Link anchor.
    .arr-tag-link-icon Icon wrapper.
    .arr-tag-link-text Visible label wrapper.
    data-id Normalized slug of the trimmed name after removing the prefix; on anchor and label.
    data-tag Full original tag, including prefix; on anchor and label.
    data-tag-name Trimmed name without prefix; on anchor and label.
    data-tag-prefix Configured prefix; on anchor and label.
    data-item-id Current item ID; anchor only.

    Different names can share a slug. Use exact data-tag-name or data-tag when needed.

    How tag slugs are generated

    Slug generation follows these steps:

    1. Decompose Unicode and remove combining accents.
    2. Lowercase and trim.
    3. Replace whitespace and unsupported characters with hyphens.
    4. Collapse repeated hyphens and remove edge hyphens.

    ASCII letters, digits, hyphens, and underscores survive. For example, 1 - n00bcodr becomes 1-n00bcodr.

    Links navigate to #!/list.html?type=tag&tag=<encoded full tag>&serverId=<server>. JE uses Dashboard.navigate when available and the equivalent hash otherwise.

    Automatic theme detection¶

    Check these variables when customizing how the panel uses your theme's colors and effects.

    JE checks identifying root CSS variables for Jellyfish, ElegantFin, and Zesty, in that order. The first nonempty identifier other than none wins. Other themes receive Default styling. These variables are supplied by themes, not defined by JE.

    Theme Detection variable Variables consumed by JE
    Jellyfish --theme-updated-on --primary-background-transparent, --secondary-background-transparent, --primary-accent-color, --text-color, --alt-accent-color, --blur, --logo
    ElegantFin --elegantFinFooterText --headerColor, --drawerColor, --activeColor, --textColor, --selectorBackgroundColor, --blurDefault
    Zesty --honey-yellow --darkest, --dark, --accent, --white, --dark-highlight, --rounding

    Reopen the panel after changing theme values. Reload to redetect a different theme.

    Theme fallbacks and cached detection

    Missing values have fallbacks. Detection is cached, but JE reads the selected theme's values again when constructing a panel and inserts them as literal styles.

    Zesty's --rounding feeds JE's blur input. Some surfaces, including the panel root and phone content background, also have fixed defaults.

    Tag size and gap hooks¶

    The layout controller sets two unitless custom properties on each .je-tag-host and its external .je-tag-caption outlet:

    Hook Values from settings Used for
    --je-tag-scale 0.85, 1, 1.15, 1.3 Multiplies responsive font-size clamps, chip padding, icons, flags, summary pills, overflow chips and indicator clearance
    --je-tag-gap 0.75, 1, 1.5 Multiplies the existing gaps between chips and groups; spacing also follows tag scale

    Both fall back to 1 in the stylesheet. Version-0 posters retain their original sizing expressions for exact legacy pixels; a layout-setting edit promotes the document and enables the multipliers. The same values reach live preview samples, including shape overrides. Caption height reserves a size/gap-adjusted two-row budget. These hooks do not change edge inset. For a web-only custom override, include both the host and caption because the caption is a sibling, not a descendant:

    .je-tag-host, .je-tag-caption {
    --je-tag-scale: 1.15 !important;
    --je-tag-gap: 0.75 !important;
}

    Saved size and gap choices also affect native posters; custom web CSS does not affect composited images. Prefer the built-in controls when the same appearance is needed in both.

    Awards chips¶

    The Awards wrapper is .awards-overlay-container, placed by the shared tag layout controller. Each .awards-tag[data-je-award] contains .awards-tag-logo (decorative bundled SVG) and a text span. Stable ids are imdbTop250, certifiedFresh, oscar, emmy, letterboxdTop250. The chip's title and accessible label include rank/year when known. On linked posters the layout wraps chips in .awards-link anchors (tabindex="-1") so hover titles and poster navigation remain reachable. Layout slots, caption outlets, caps and hover suppression apply as for other groups. Tag Styles supplies Awards group and per-label background/text/inner-border colours. SVG source colours remain their identifying colours; CSS cannot change native image pixels.

    Quality stream display¶

    All-mode chips reuse .quality-overlay-label, .audio-codec, .video-format and .video-codec inside .quality-overlay-container. Each distinct sound codec/channel combination is a separate chip; data-quality retains its base codec for existing colour selectors. SDR uses .video-codec[data-quality="SDR"] and is also an editable Tag Styles label. There is no new wrapper or per-card layout measurement. Minimum-resolution and Hide SDR filtering remove chips before layout and overflow fitting, so CSS does not need to hide them.

    Technical quality, SDH and Scenes hooks¶

    Technical chips retain .quality-overlay-label.other-quality with data-je-quality-category="runtime", "aspectRatio" or "frameRate"; data-quality uses the same stable category id. data-je-compact contains the shortened display text. They inherit Quality Tag Styles. SDH subtitle chips keep .language-chip, .language-cc and data-je-language="subtitles", and add data-je-sdh="true"; the marker and accessible tooltip survive Summary presentation. Status scene chips use .status-tag--scenes and data-je-status="post_credits" / "mid_credits", available as Status labels in Tag Styles. These hooks exist only when the corresponding chips are shown.

    Flush box chips and genre chips (.genre-tag) retain their border-box size, with transparent touching-side borders, square corners against the edge and clip-path clipping only those sides of the shadow. The inward shadow and border keep their group styles, and a genre's floating .genre-text name is not clipped. Language flag images keep their shape. Centre rows use --je-anchor-reserve to fit between indicators; data-je-flush-detached marks a top-centre row that must move below them because its first chip cannot fit. Bottom-centre Flush uses the progress bar's top edge directly. These rules apply only to Corners hosts with data-je-edge="flush".

    Flush also styles direct .je-tag-more overflow chips. Configured Rating/Awards inner rings keep outline-offset: -1px; touching chips paint the ring through an inert ::after border with only inward sides. Centre chips retain their ordinary outline. Scoped Media Tags previews use the same Flush rules.

    Middle-side Corners slots (data-je-slot="ml" / "mr") receive --je-anchor-width from the batched fit pass. A first centre chip constrained to its slot carries data-je-fit-width and --je-chip-fit-width; its text uses an ellipsis. For link-wrapped Awards and Language chips, the wrapper carries the width budget through to the actual chip; truncate the label inside that chip to preserve its rounded inward edge, border and ring. Flush paint reaches the chip through its transparent link. These are measured geometry hooks: overriding them can overlap the opposite side. Genre hover names remain inside the same width budget.

    Language text chips (.language-chip, including .language-code and .language-count-badge) share tagRenderer.chipBaseCss with quality chips. data-je-language-label is the lowercase displayed code or dual/multi; Tag Styles paints it over the kind and language-group colours. .language-flag images keep their ring, and .language-flag-partial only adds the dashed treatment on images (text chips dim).

    The item editor sample (.je-tie-card) is focusable and labelled. Its .je-tie-view [data-view] buttons pin Hover or return to Resting; pointer and focus interaction share the hub preview helper and toggle .je-tag-reveal on that sample.
