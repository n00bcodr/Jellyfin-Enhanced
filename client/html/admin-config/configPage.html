dashboard
The essential enhancement suite for Jellyfin, bundling advanced features and customizations into one convenient plugin.

This Overview is a read-only snapshot of:
• Service connection health
• Which optional companion plugins are installed
• Which features are enabled or misconfigured

To turn features on or off, use the other tabs (Display, Playback, Pages, Seerr, *arr, Extras, ...).
Clicking any card here jumps straight to the tab that owns it.
person
Many of these are personal settings.
What you set here is the default every user starts with. Each user can change their own copy in the Enhanced Panel (sidebar link, user menu, or press ? while browsing).
Changing a setting here does not change existing users. A setting with the small people icon shows a banner in its card when you change it: Apply the above copies just the changed settings to every user, and Apply all plugin settings copies all of them.

integration_instructions
These features add or replace pages in the Jellyfin web UI. Support integration with Plugin Pages (sidebar) or Custom Tabs (home page).
On Jellyfin 12's Modern Layout, sidebar links (including Plugin Pages) only appear on mobile, not desktop, a limitation of that layout's nav drawer. Use the native Home tab option below for a desktop-visible entry point on Jellyfin 12.
download_for_offline
Connect Jellyfin Enhanced to your Sonarr, Radarr, Bazarr, Shoko and Maintainerr instances.
Each service gets its own box below; add as many Sonarr/Radarr instances as you want (one per quality profile / library), plus a single Bazarr endpoint and a single Shoko endpoint. Each instance can be enabled, disabled, or removed independently.
hub
Third-party services Jellyfin Enhanced can talk to, in one place: keys, connection tests and the features that depend on them. Each card here is a linked copy of the one in its feature tab, so changing it in either place changes both. Seerr and the *arr apps have their own tabs.
